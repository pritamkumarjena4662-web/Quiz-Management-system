# Quiz Management System

A web-based Quiz Management System designed to provide an easy and user-friendly platform for conducting and managing online quizzes.

## Features

- Student Login
- Student Registration
- Student Dashboard
- Admin Dashboard
- Quiz Management
- Question Management
- Online Quiz
- Quiz Results
- Responsive User Interface
- Easy Navigation

## Technologies Used

- React.js
- JavaScript
- React Router DOM
- Tailwind CSS
- Vite
- HTML5
- CSS3
